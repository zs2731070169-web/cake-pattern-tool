### 7.5 已知风险与运维点

- **同步单外呼 ~1s**（3425px 直出实测），远快于佐糖（~8s+尾程）与两段方案（16-30s）；繁忙（code=3）重试一次的防御保留；
- 大图版与基础版同管线（锐化型）——**质量上限低于高级版生成式重建**，此为用户知悉后的定案取舍（简单优先）；若未来质量投诉，升级路径已探明：两段链路（7.3 弃用行）或等石榴修高级版 width bug；
- 失败降级链：失败/超时/未配 → 本地 INTER_LANCZOS4 保交付（记 done(interpolated)）；
- 石榴依赖收拢（去水印 auto_inpaint_advanced + 超分 large_resolution 两端点同一积分池）——积分余额监控纳入运维（价目表"积分查询API 0 积分"端点待接，现阶段人工登控制台）。
